PlanGo AI - Your Smart Travel Companion 🌍✈️
PlanGo AI is a modern web application designed to help travelers generate personalized, day-by-day travel itineraries in seconds. By leveraging generative AI, the application takes user inputs such as destination, trip duration, budget tier, and personal interests to build a fully customized travel plan.

Built as part of a collaborative vocational IT project (June 2026).

🚀 Features
Customized Itineraries: Generates structured, day-by-day plans tailored to specific trip lengths and group sizes.
Smart Budget Allocation: Adapts travel recommendations dynamically based on Budget, Standard, or Luxury preferences.
Interest-Based Travel: Customizes the journey based on preferred categories such as Beach, Adventure, Culture, Food, or Nature.
Modern Responsive Interface: A clean, welcoming UI featuring inspirational cards for popular destinations like Paris, Tokyo, and Bali.

🛠️ Tech Stack
Frontend: HTML5, CSS3, Jinja2 Templates
Backend Framework: Python, Flask
AI Integration: Google GenAI SDK (Model: gemini-3.5-flash)
Infrastructure & DevOps: AWS EC2 (Amazon Linux 2023), Git, Virtual Environments (Python 3.11)
